# Trevani website

Plain HTML/CSS website for trevani.in. There's no build step.

## Put it online with GitHub + Vercel

1. Create a new GitHub repository (for example `trevani-website`).
2. Upload **everything inside this folder** to the repository's main page, so that `index.html` sits at the top level, not inside another folder.
3. On vercel.com choose **Add New → Project**, then import the repository.
4. Leave the settings as they are: Framework Preset **Other**, no build command, no output directory. Click **Deploy**.
5. In the Vercel project, go to **Settings → Domains** and add `trevani.in`, then follow Vercel's DNS instructions at your domain registrar.

## Editing

- Each page is a separate `.html` file. Colours and layout are in `css/site.css`.
